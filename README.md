> **OCR 助手** — 四种模式(悬浮窗 / 自由截图 / 迷你条 / 翻译)· 云端与端侧双 OCR · 大模型图文答题的桌面工具。
> 界面由 **React 18 + Tailwind CSS** 构建,后端为 Python(截图 / OCR / 模型调用 / 配置)。

把捕获区对准屏幕上的任何内容(题目、文档、网页、代码…),一键完成 **截图 → 文字识别 → 大模型理解回答**;识别结果与回答左右分栏、白色卡片展示,文字可直接拖选复制,窗口底部状态栏实时显示识别引擎、模型与耗时。全程无需切换窗口。

## 四种模式

| 模式 | 说明 | 快捷键 |
|---|---|---|
| **悬浮窗模式** | 透明洞口常驻置顶,洞内即捕获区;**洞内鼠标可直接穿透**,点击直达后方内容;四边四角可拖拽缩放窗口 | `Ctrl+1` |
| **自由截图模式** | 全屏半透明遮罩,拖拽框选任意区域;操作条内嵌引擎开关/语言方向/提问,可「识别 / 翻译此区域 / 设为悬浮窗区域」 | `Ctrl+Shift+A` / `Ctrl+3` |
| **迷你条模式** | 图标工具条 + 单行提问输入行(悬停显示说明),首次自动居中停靠在任务栏上方,可自由拖动;宽度有下限,保证右上角按钮不会因缩窄而消失 | `Ctrl+2` |
| **翻译模式** | 无洞口窗口,原文与译文**左右两栏**、白色卡片、可拖选复制、各自滚动;支持端侧离线翻译 | `Ctrl+4` |

> 顶部切换器或快捷键可随时切换模式;`Ctrl+F1` 在悬浮窗模式触发识别,在迷你条模式直接进入框选。
> 四种模式的窗口都按主题圆角收角(设置窗口除外)。

## 功能特性

- **新手教程(气泡 + 箭头)**:四种模式 + 设置窗口各有一套引导,首次进入某模式自动开始;目标控件高亮描边、周围压暗,气泡说明 + 箭头指向,支持 上一步/下一步/跳过;教程期间自动暂停洞口穿透,结束后恢复。设置页「新手教程」可重播任意模式或一键重置
- **透明洞口悬浮窗**:仅洞口透看目标,其余为不透明面板;拖动定位,窗口尺寸与位置自动记忆
- **洞口鼠标穿透**:洞内点击直达后方内容(可一边看题一边作答),洞口边框仍保持可见
- **窗口拖边缩放**:四边/四角都可拖动改变大小,尺寸与位置自动记忆(高 DPI 下按缩放比正确换算)
- **双 OCR 模式**:云端(所选大模型识别,精度高)/ 本地(内置 RapidOCR,离线免费,约 50MB,CPU 100-300ms);主界面一键切换
- **双翻译模式**:云端大模型翻译 / 端侧离线翻译(Argos 端侧模型,可选本机 Ollama),语言方向可选并注入请求
- **双语对照**:识别原文按句/段切分,原文一段、译文紧随其下;可切换双语 / 仅译文 / 仅原文
- **多 AI 平台**:阿里云百炼 / OpenAI / DeepSeek / 智谱 GLM / Kimi / Ollama,支持自定义平台;已配置与未配置分区显示、悬浮删除、名称可编辑
- **图文答题**:OCR 文字 + 截图图片同时发送模型,并结合题目结构化解析(题型 / 题目 / 选项);可关闭思考模式提速
- **本地知识库**:关键词命中即返回答案,免 API 调用;AI 回答可自动入库
- **全局主题 + 自定义主题**:浅色 / 深色 / 灰色 / 护眼 / 高对比 5 套预设,支持逐项配色(含面板/卡片/内嵌区三层分区色)、圆角、字号、面板不透明度、洞口边框样式;主题可导出/导入 JSON,所有窗口实时同步
- **自定义图片背景**:可为面板铺一张本地图片,并单独调节不透明度 / 模糊 / 压暗 / 填充方式;悬浮窗洞口始终透明,不影响穿透与截图
- **扁平图标界面**:全部图标为内置 SVG(无 emoji),悬停显示文字说明(提示框会自动避让洞口),紧凑不占空间
- **识别历史(时间线)**:竖轴 + 相对时间,顶部有「总记录 / 知识库命中率 / 平均耗时」统计卡,支持按 全部/答题/翻译/知识库 过滤、单条展开全文与复制
- **请求记录**:GitHub 风格灰→绿方格图 + 请求次数 / 失败数 / 成功率 / 平均耗时统计卡
- **可编辑 JSON 请求模板**:实时预览 + 格式校验,支持自定义模型参数
- **单行提问输入**:各模式的提问/指令框均为单行输入,**Enter 直接触发对应动作**(悬浮窗→识别、翻译→重新翻译、迷你条→框选识别、框选→识别);自己输入的内容自动记忆,示例可在设置中维护
- **云端 / 本地 分段开关**:顶栏的识别引擎开关为两段式胶囊,选中项高亮;切换到端侧后右上角会同步显示端侧档位(而不是仍显示云端模型名)
- **模态设置窗口**:设置打开期间主界面自动禁用输入,避免来回误操作,关闭设置即恢复
- **更多设置**:图片压缩上限、默认提问、**8 项可自定义快捷键(按键录入)**、缓存与题目保存位置、回答自动入库、连通性测试(含响应耗时)

## 技术架构

```
┌────────────── 前端 React 18 + Tailwind(Vite 构建) ──────────────┐
│  index.html?view=overlay | mini | translate | settings           │
│  selector.html(全屏框选)                                        │
│  组件:Overlay / MiniBar / Translate / Settings / Snip / Guide    │
│        QuitDialog / ui(通用控件) / theme(主题与背景图) / bridge    │
└─────────────────────────────┬───────────────────────────────────┘
                     pywebview js_api(JSON 桥)
┌─────────────────────────────┴───────────────────────────────────┐
│  后端 Python                                                    │
│   manager(窗口/模式/流程/托盘/热键) · api(桥) · mainthread(主线程)│
│   capturer(mss 截图) · winutil(DPI 换算/洞口区域)                │
│   agent(模型调用) · worker(识别与翻译流程) · question_parser      │
│   local_ocr(RapidOCR) · local_mt/local_hf(端侧推理)              │
│   local_translate(端侧翻译) · local_models(模型下载与管理)       │
│   config / history / request_log / clipboard                     │
└─────────────────────────────────────────────────────────────────┘
```

- 桌面容器:**pywebview**(Qt / WebEngine 后端),支持透明、无边框、置顶、拖拽与全局热键
- 窗口与 WebView 操作统一通过 `app/mainthread.py` 排队到 Qt 主线程执行
- 截图坐标与洞口区域统一由 `app/winutil.py` 换算(逻辑像素 ↔ 物理像素,适配高 DPI 与多显示器)

## 安装与运行

### 方式一:打包版(推荐)

从 [Releases](../../releases) 下载对应版本的可执行文件,双击运行。

### 方式二:源码运行

```powershell
git clone https://github.com/TDCQCX/OCR-Assistant.git
cd OCR-Assistant

# 创建虚拟环境并安装依赖
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt

# 启动(或双击 start.bat)
.\.venv\Scripts\python.exe main.py
```

### 前端开发(可选)

```powershell
cd frontend
npm install
npm run build     # 构建到 app/webui,后端自动加载
npm run dev       # 浏览器热更新调试
```

## 快速开始

1. 启动后进入**悬浮窗模式**,中部红色边框区域即捕获洞口。
2. **定位**:按住顶部/底部面板拖动窗口,使洞口对准目标;需要改变窗口大小时拖动窗口的四边或四角。
3. 在「提问/指令」框填写问题(默认:请给出该题目的答案),按 `Enter` 或点「识别」。
4. 数秒内即可看到【识别结果】与【回答】;两栏文字都可直接拖选复制,底部状态栏显示本次用的引擎、模型与耗时。
5. 需要临时框选时按 `Ctrl+Shift+A` 进入自由截图模式,拖拽框选后选择「识别」「翻译此区域」或「设为悬浮窗区域」。

> 首次使用请先在「设置 → 模型设置」中为所选平台填写 **API Key 与模型 ID**(仅保存在本地 `config.json`)。

## 配置说明

点击顶部「设置」打开设置窗口(左侧导航):

- **模型设置**:左侧 AI 平台列表固定在窗口中(只有列表自身在超出时滚动),右侧为表单;含已配置/未配置分区、单选「当前使用」平台、常用模型下拉、连通性测试、备注、官网、API Key、模型 ID、Base URL、思考模式、JSON 请求预览与模板编辑
- **常规设置**:AI 设置(云端/本地 OCR、最长响应时间、重试次数、图片压缩上限)、保存设置(缓存/题目目录、自动入库)、行为与 **8 项快捷键(点输入框后直接按下组合键录入)**、提示词设置
- **翻译设置**:翻译引擎(云端/端侧)、端侧引擎、默认语言方向、展示方式、**端侧模型管理(按需下载/换档/删除)**、自动刷新、提问与提示词
- **外观主题**:5 套预设 + 自定义配色编辑器 + 圆角/字号/面板不透明度/洞口边框 + **自定义图片背景** + 主题导入导出
- **识别历史**:时间线回看(统计卡 + 过滤 + 展开 + 复制)与清理
- **新手教程**:重播任意模式的引导、一键重置
- **关于应用**:版本信息、请求记录图与统计、GitHub 与 QQ 群、开源许可证

配置按用途分组:`active_provider` / `providers` / `prompts` / `request_template` / `mode` / `ui`(含主题与背景图)/ `window` / `capture` / `timeout` / `retry` / `ocr` / `translate` / `local`(端侧档位与下载源)/ `knowledge` / `hotkeys` / `behavior` / `storage` / `app`。
写入前会自动把上一份留档为 `config.json.bak`,误改 Key 或配置写坏时可直接找回。

## 常见问题

- **提示"未配置 API Key"**:在「设置 → 模型设置」为当前平台填写 Key 并保存(关闭设置窗口即自动保存)。
- **接口返回 401/403**:API Key 无效或无该模型权限;可用「测试连通性」快速排查。
- **本地 OCR 报错**:确认为源码环境安装了 `rapidocr_onnxruntime`。
- **截图区域与洞口不一致**:程序已做 Per-Monitor V2 DPI 感知,支持多显示器与不同缩放,并把窗口坐标统一换算为物理像素;如仍异常请反馈你的缩放比例与窗口位置。
- **设置页切换有点慢**:端侧模型状态的目录体积统计已做缓存与后台刷新(`models/` 下常有数千个文件);若首次打开仍偏慢,属一次性统计,稍后会恢复。
- **提示词 / 请求模板如何改**:设置 → 常规设置(提示词)、模型设置(JSON 预览 → 编辑模板)。

## 端侧(离线)模型

端侧识别与翻译**不联网、免费**,模型不随应用分发,首次使用时按需下载:

- 打开「设置 → 翻译设置 → 端侧模型管理」,按需下载:
  - **OCR 识别模型**三档:轻量(约 16MB)/ 均衡(约 120MB,推荐)/ 全量(约 196MB);
  - **端侧翻译**:轻量(专用小模型)/ 均衡 / 全量(官方 NLLB-200,质量更好但体积与耗时更大);
  - **推理运行时**:轻量档约 62MB;均衡/全量档需官方运行时(约 2.5GB,仅一次)。
- 国内网络可在同一处把下载源切到 **hf-mirror**。
- 也可以改用本机 [Ollama](https://ollama.com)(设置 → 翻译设置 → 端侧引擎选 Ollama)。
- 源码环境仍保留 `argostranslate` 作为备用引擎(非必需):
  `.\\.venv\\Scripts\\python.exe -m pip install argostranslate`
